# Hero Images Instructions

For the best appearance of your homepage, please add the following images:

1. `hero-slide-1.jpg` - Premium Stationery image (recommended size: 1920x1080px)
2. `hero-slide-2.jpg` - Back to School Collection image (recommended size: 1920x1080px)
3. `hero-slide-3.jpg` - Office Essentials image (recommended size: 1920x1080px)

Until you add these images, the hero slides will use the fallback gradient backgrounds defined in the code.

## Image Recommendations:

- Use high-quality images that represent each category
- Optimal resolution: 1920x1080px (16:9 ratio)
- Make sure images are web-optimized (compressed) for faster loading
- Use images with some darker areas or overlay to ensure text remains readable

A placeholder SVG file (`placeholder-hero.svg`) is included as an example.
